# Privacy Policy

DeepSeek Inline Completion does not collect or store personal data.

The plugin sends code context to the DeepSeek API only for generating code completions.

The following data may be sent to the DeepSeek API:

- Code near the cursor (prefix and suffix)
- Programming language information
- Prompt text used for completion

No user identity information is transmitted.

API keys are stored locally using IntelliJ Password Safe and are never uploaded.

The plugin does not track usage analytics or telemetry.
